3.7.2 更新日志
---------------------------------------
新增功能
---------------------------------------
【自动后宅】
  · 自动把舰船安排进宿舍，优先选当前出击舰队里拥有的舰船
  · 按心情值决定优先级，后宅优先2层，没空位后放入1层
  · 开启方式：Tasks → AutoDorm（需同时开启 Tasks.Enabled）
【自定义MVP优先顺序】
  · 新增「MVP优先顺序」功能，可以指定由哪个舰队位置的舰娘拿下每场战斗的 MVP。
  · 开启方式：Misc → CustomSVP，填入一串位置序列，例如 6>5>4>3>2>1，或者1,3,4,5,2,6
  · 序列按从前到后的顺序挑选，只会选中本场实际出战的位置；序列里写了但本场不存在的位置会自动跳过，顺延到下一个。
  · 位置编号沿用游戏内的编队顺序：主力 1-3、先锋 4-6、潜艇 7-9。
  · 留空表示关闭该功能；分隔符可以用 > 、 , 、 ; 、 | 或空格。
