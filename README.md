Redesigned menu interface for enhanced clarity

Added restore function to the Update page, reverting Mod versions to the original APK version
Added OBB version prompts—When the game freezes, you can take a look.
Starting from 3.2.0, future updates can be applied via patching. Operation directory: /storage/emulated/0/Android/data/{game_package_name}/files/
Upgrade: Place MOD_MENU_xxx.zip (must be this format) in the directory. The game will automatically upgrade and delete the zip upon launch.
Restore: Place an empty file named RESTORE_MOD_MENU in the directory. The game will force a version restore and delete this file upon launch.
